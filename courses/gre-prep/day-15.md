# Day 15: Checkpoint 3 — PowerPrep Dress Rehearsal

**Date:** August 18, 2026 · **Time budget:** ~2 hours (the test itself)

Four days out from the real exam. This is the most accurate score
predictor available — official ETS software, the actual adaptive
algorithm, the actual question style — and the last major data point
before Aug 22. Like Day 9, the whole day is the test; no Hour 1/Hour 2
split, nothing layered on top.

## Why this one matters more than Checkpoint 2

Kaplan's test (Checkpoint 2) told you real things, but it's not built by
ETS and doesn't run the real section-adaptive algorithm. **PowerPrep is**
— same test-maker, same software, same item pool style as Aug 22. If
something is going to surface a real problem before it costs you on the
actual exam, this is where it happens.

## The test

Use your second reserved **official ETS PowerPrep test** (the first was
saved specifically for this day — see [How It Works](/how-it-works)).
Open the PowerPrep software you installed when you registered.

## Conditions — no exceptions this time

- **One sitting, start to finish, real timing.** Analytical Writing first
  (Issue essay only, 30 min), then Verbal and Quant in whatever order the
  software gives them.
- **No notes, no cheat sheet, no looking anything up.** This is the
  closest thing to Aug 22 you'll get before Aug 22 — treat it accordingly.
- **Use the actual break structure the software gives you, and no more.**
  Same logic as every timed section this whole course has run on.
- **Quiet space, phone away, nothing else open.**
